# 場內淨空的安裝方案

上一版相機 C 等位置不適合比賽或實際投球動線。新版以「活動區內沒有設備、落地支架或橫跨線材」為部署約束；界外區也納入活動區，不是跨過界外線就可架設備。場地與界線仍為示意，不能當作特定球場的安全核可圖。

## 配置調整

| 設備 | 牛棚／室內 | 球場 |
| --- | --- | --- |
| 相機 A、B | 捕手後方護網外固定；釋球研究模式移至兩側網外 | 本壘後方左右結構上，長焦對本壘 |
| 相機 C | 投手側護網外剛性柱／牆固定 | 三壘側看台固定點，長焦對釋球區；示意 x=-32 m、高 8 m、z=-18 m |
| 相機 D | 側網外高位斜視 | 本壘後方高位斜視；不是球員上方懸掛設備 |
| E、F、G、H | 不需要全部配置 | 一三壘側看台、外野牆後；不能把落地桿放在外野草地 |
| 24 GHz 雷達 | 捕手後方網外，驗證視線與網材 | 本壘後方固定；場外距離下需重新驗證高速小球回波 |
| 60 GHz 雷達 | 側網外短距研究 | 場外可選節點；若距離、雜波、速度範圍不適合就省略，不以場內擺設備換取訊號 |
| FPGA、網路與電源 | 網外維護區箱體 | 場外機櫃；沿既有線槽布線 |

優先利用球團已有的牆面、看台結構、攝影平台與核准安裝點。固定於剛性結構，不能綁在晃動網面。光學穿網的解析度與網紋、雷達穿網的衰減與反射各自實测；金屬网不能當成無影響。防護罩的影像畸變與雷達透波性也需納入校正與驗證。

Demo 以短支架＋灰色結構示意固定點，代表需場勘確認的安裝結構，並非要求新設那些柱子。界線按鈕顯示示意活動範圍，圓環表示節點投影。程式檢查設備／機櫃／支架包絡留在界線外，未模擬球員衝撞、護網撓度、結構載重及真實通道淨寬。

## 移遠後如何維持量測

相機不需靠近球才能追球心，但距離增加會減少球體像素，需要調整焦距、解析度、曝光與照明，並保留足夠的交會角。兩台遠距相機若幾乎同方向看球，即使都看得到球，深度誤差仍可能很大。新增視角應優先解決遮擋與幾何退化，而不是只加相機數量。

針孔模型下，接近光軸的球體像素直徑約 `d_px = f_px × D / Z`，其中 `f_px = W_px / (2 tan(HFOV/2))`。以下是單純投影估算，不是產品性能或精度保證：

| 影像寬度 | 水平視角 | 軸向距離 | 球直徑 7.32 cm 的像素數 |
| --- | --- | --- | --- |
| 1920 px | 30° | 30 m | 約 8.7 px |
| 1920 px | 10° | 30 m | 約 26.8 px |

像素多不代表必然準確，還有運動模糊、量子噪聲、鏡頭畸變、熱漂移、時間同步、遮擋與重建幾何。窄視角也使覆蓋縮小，因此釋球、本壘、擊球與守備可使用不同焦段並共用時間、場地座標與邊緣主機；共用系統不等於所有任務用同一鏡頭。

轉速尤其不能和球心追蹤混為一談。遠距球體只有數十像素時，是否足以穩定辨識球縫必須實測；場外相機 C 不能承諾直接取得球縫轉速。先在牛棚網外設專用近攝研究，通過驗證才保留此量測；否則轉速欄位保持缺值或明確標為模型估計。

## 場勘需要球團提供

- 球場與牛棚尺寸、護網位置和材質、球員／工作人員動線、球團認定的設備禁入區。
- 既有攝影平台、看台／牆面固定點的座標、高度、載重及可取得的施工與維護方式。
- 各固定點面向本壘／釋球區的照片或現場視線檢查，包含打者、捕手、主審、觀眾與廣告造成的遮擋。
- 可用電力、網路／光纖、線槽、機櫃、防雨、防雷與夜間照明條件。

先場勘與試拍 → 估計球體像素及曝光 → 檢查交叉視角 → 固定與校正 → 獨立量測驗證。FPGA 可減少影像運算和傳輸負載，無法補回沒有進入鏡頭的光學資訊。
